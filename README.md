# No More Bookmarks

_Transform Your Bookmarks Into Real Experiences_

> A personal archive platform that helps you transform from "someone who bookmarks" to "someone who executes" by tracking and recording your actual experiences from social media inspirations.

**🔗 Live Demo**: TBA <br>

## Project Background

As someone who constantly bookmarks travel destinations, recipes, and experiences on Instagram and YouTube but rarely follows through, I created this platform to solve my own problem. It's a tool I genuinely wanted to use to transform my digital inspiration into real-world experiences.

Unlike typical social media platforms that focus on showcasing and impressing others, this platform is fundamentally designed as a personal archive. Rather than seeking external validation through likes and follows, the core purpose is to provide personal satisfaction by viewing your own achievement records—transforming your identity from "someone who just bookmarks" to "someone who executes."

## Core Problem & Solution

**Problem**: We save countless inspiring content on social media but struggle to convert these bookmarks into actual experiences.

**Solution**: A dedicated platform that bridges the gap between digital inspiration and real-world execution, helping users build an identity as "someone who does" rather than "someone who just saves."

## Key Features

### Implemented Features

- **User Authentication**: Secure signup/login system with Supabase Auth
- **Experience Recording**: Create detailed posts linking bookmarks to real experiences
- **Personal Feed**: Browse and discover your own journey of completed experiences

## Technical Implementation

### Tech Stack

- Next.js 14
- TypeScript
- Subapase
- TailwindCSS + ShadcnUI
- Vercel

### Architecture Decisions

- **Server Components**: Leveraging Next.js 14's server components for optimal performance
- **Real-time Updates**: Supabase real-time subscriptions for live feed updates
- **Responsive Design**: Mobile-first approach considering the mobile nature of social media bookmarking
- **Type Safety**: End-to-end TypeScript implementation from database to UI
